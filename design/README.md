## Создать редактируемые макеты в Figma
В пустом Design-файле: Plugins → Development → Import plugin from manifest…
Выбрать figma-plugin/manifest.json и запустить Trail Notes — Workshop Redesign.
Он создаёт новую страницу с четырьмя native Frame, редактируемым текстом,
фигурами, векторами и шестью цветовыми стилями. Ничего не удаляет, сеть не использует.
Генератор статически проверен, запуск в Figma пока не проверен.
Альтернатива: перетащить SVG в Figma; это не сохраняет семантику native текста
так же надёжно, как генератор. Auto Layout генератор не создаёт.

После создания скопировать ссылки на Frame 01 и 02 для задачи A.
Проверить, что MCP участника возвращает эти узлы и скриншоты.
Для упражнения с офлайном дать также ссылки на Frame 03 и 04.
