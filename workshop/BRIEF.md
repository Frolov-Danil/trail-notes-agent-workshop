# Trail Notes — практикум із паралельної роботи з агентами

Продукт: бібліотека коротких матеріалів про прогулянки. Два екрани: список і стаття.
Старт: React Native + Expo + TypeScript, локальний HTTP API, без постійного кешу.
Мета: два агенти в окремих worktree, два перевірені результати, локальне об’єднання.
Push і PR учасникам не потрібні.

## Розклад, 90 хвилин

1. 0–10: вступ і критерії результату.
2. 10–20: два worktree, два чати й перевірка MCP.
3. 20–25: плани агентів та узгодження інтерфейсу між задачами.
4. 25–50: паралельна реалізація.
5. 50–65: перевірка результатів і локальні коміти.
6. 65–80: послідовне об’єднання та виправлення.
7. 80–90: загальна демонстрація й розбір.

Повний сценарій, команди, промпти та приймання: [FULL-PLAN.md](FULL-PLAN.md).
Стартова версія: тег `workshop-v1`.

## До зустрічі

- Учасник клонує проєкт, виконує npm ci та запускає API і Metro за README.
- Ведучий перевіряє доступ до GitHub і Figma та читання потрібних вузлів через MCP.
- Для порівняння оформлення обрати однаковий розмір екрана, світлу тему й стандартний шрифт.
- Основну перевірку учасник робить на знайомій платформі; бандли експортує для обох.
- Для worktree призначити окремі порти Metro.
- У кожного учасника власний локальний клон; робочий репозиторій компанії не використовувати.
- Не показувати готову реалізацію редизайну або кешу.

## Що оцінюємо

Учасник формулює критерії, перевіряє план агента, помічає вихід за межі задачі,
читає diff та пояснює результат. Після merge показує роботу онлайн, офлайн
із кешем, офлайн без кешу й повторне завантаження.
