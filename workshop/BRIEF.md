# Trail Notes — практикум по параллельной работе с агентами

Продукт: библиотека коротких материалов о прогулках. Два экрана: список и статья.
Старт: стандартный SwiftUI, локальный HTTP API, без постоянного кеша.
Цель: два агента в отдельных worktree, две проверенные ветки, общее слияние.

## Тайминг, 75 минут
1. 10 минут: запуск, осмотр кода, критерии результата.
2. 30 минут: параллельные задачи, участник управляет обоими агентами.
3. 10 минут: проверка каждой ветки и коммиты.
4. 15 минут: слияние и общая проверка.
5. 10 минут: разбор промптов, ошибок и стоимости изменений.

## Перед встречей
- Открыть TrailNotes.xcodeproj и запустить API по README.
- Проверить доступ участника к Figma и получение нужных узлов через его MCP.
- Установить одинаковый iPhone Simulator, светлую тему и стандартный размер текста для визуального сравнения.
- У каждого участника отдельный клон и свой baseline. Не использовать рабочий репозиторий продукта.
- Не показывать участнику готовую реализацию редизайна или кеширования.

## Что оцениваем
Участник формулирует критерии, проверяет план агента, замечает расширение задачи,
читает diff и объясняет результат. После merge воспроизводит онлайн, офлайн
с кешем, офлайн без кеша и повторную загрузку. Рабочий экран без проверки — не финиш.
