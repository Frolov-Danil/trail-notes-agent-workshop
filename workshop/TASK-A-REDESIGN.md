# Задача A — редизайн через Figma MCP

Онови два екрани Trail Notes за макетами нижче.
Спочатку отримай структуру, властивості й зображення цільових вузлів через MCP.
Покажи короткий план, потім реалізуй зміни після навчальної контрольної точки.
Збережи навігацію й завантаження. Постійний кеш виконує інший агент.
Контракт ArticleService не змінювати.

## Критерії приймання

- Список і стаття відповідають Figma 390 × 844: кольори, ієрархія, відступи й картки.
- Кожна картка відкриває правильну статтю; повернення до бібліотеки працює.
- Довгі заголовки, малий екран і збільшений системний шрифт залишаються читабельними.
- Loading, error та empty стани збережено.
- Іконки й вектори працюють на обох платформах; не прив’язуватися до SF Symbols.
- Не додавати віддалені зображення. Нові залежності узгодити й зафіксувати в lockfile.
- Поведінку офлайн робить агент B. Підготуй окреме оформлення банера з props
  та узгодь з учасником його інтерфейс.
- Власна робоча копія має збиратися без ще не доданих агентом B полів стану.
- Покажи порівняння з макетом, перевірки та перелік змінених файлів.

Основні файли: LibraryScreen.tsx, ArticleScreen.tsx, візуальні компоненти.
Зміни useLibrary.ts попередньо узгодити через учасника.
Працювати лише у своєму worktree. Локальний коміт створити, merge/push/PR не робити.

Перевірки: npm run typecheck, npm test, Expo export для iOS та Android;
мобільна візуальна перевірка на платформі учасника. Вебперегляду недостатньо.
