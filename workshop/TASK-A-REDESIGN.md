# Задача A — редизайн через Figma MCP

Обнови два экрана Trail Notes по макету Figma, указанному ведущим.
Сначала получи структуру, свойства и изображения целевых узлов через MCP.
Покажи краткий план, затем реализуй изменения. Сохрани навигацию и загрузку.
Не реализуй кеширование и не меняй контракт ArticleServing.

## Приёмка
- Список и статья соответствуют макету 390 × 844: цвета, иерархия, отступы, карточки.
- Все карточки открывают правильную статью, назад возвращает к списку.
- Длинные заголовки, маленький экран и Dynamic Type не обрезают основной текст.
- Loading, error и empty состояния остаются доступными.
- Иконки SF Symbols; не добавляй зависимости и удалённые изображения.
- В Figma есть варианты offline, но их поведение выполняет задача B.
  Подготовь переиспользуемое оформление баннера и передай агенту B его API.
- Покажи сравнение с макетом, результат сборки и список затронутых файлов.

Зоны: LibraryView, ArticleView, новые компоненты и токены оформления.
LibraryModel согласовывать со вторым агентом, не переписывать самостоятельно.
