# Задача A — редизайн через Figma MCP

Обнови два экрана Trail Notes по макету Figma, указанному ведущим.
Сначала получи структуру, свойства и изображения целевых узлов через MCP.
Покажи краткий план, затем реализуй изменения. Сохрани навигацию и загрузку.
Не реализуй кеширование и не меняй контракт ArticleService.

## Приёмка
- Список и статья соответствуют макету 390 × 844: цвета, иерархия, отступы, карточки.
- Все карточки открывают правильную статью, назад возвращает к списку.
- Длинные заголовки, маленький экран и масштабирование системного шрифта не обрезают основной текст.
- Loading, error и empty состояния остаются доступными.
- Используй кроссплатформенные иконки/векторы; не привязывай оформление к SF Symbols. Не добавляй удалённые изображения. Зависимости согласуй и фиксируй в lockfile.
- В комплекте макетов есть варианты offline, но их поведение выполняет задача B.
  Подготовь переиспользуемое оформление баннера и передай агенту B его API.
- Покажи сравнение с макетом, результат сборки и список затронутых файлов.

Зоны: LibraryScreen.tsx, ArticleScreen.tsx, новые компоненты и токены оформления.
useLibrary.ts согласовывать со вторым агентом, не переписывать самостоятельно.

Проверка: npm run typecheck, npm test, Expo export для iOS и Android;
визуальная проверка на обеих платформах. Веб-превью само по себе недостаточно.
