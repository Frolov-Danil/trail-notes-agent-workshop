# Локальне об’єднання

1. Перевірити локальні коміти та чистоту обох worktree.
2. Відкрити чат агента в основному клоні.
3. Через git worktree list --porcelain визначити локальні результати двох задач.
4. Послідовно злити редизайн, потім офлайн, зберігши окремі merge-коміти.
5. При конфлікті прочитати обидві версії й зберегти обидві поведінки.
6. Виконати npm ci, перевірку типів, тести й Expo export для обох платформ.
7. Перевірити два екрани онлайн на мобільній платформі учасника.
8. Завантажити дані, зупинити Python API, залишити Metro ввімкненим.
9. Повністю закрити й відкрити проєкт: список і повний текст доступні з кешу.
10. Запустити API, оновити: статус зникає, дані актуальні.
11. Очистити лише кеш Trail Notes, зупинити API: зрозуміла помилка й повторна спроба.
12. Перевірити збільшений шрифт, малий екран і загальний diff.

Відсутність текстових конфліктів не замінює перевірку поведінки.
Усі результати залишаються локально, push і PR не потрібні.
