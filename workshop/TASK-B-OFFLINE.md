# Задача B — офлайн-чтение

Добавь постоянный кеш последнего успешно загруженного списка и полного текста
статей. Согласуй с агентом редизайна точку отображения статуса в LibraryView.
Сохрани текущий UI настолько, насколько позволяет офлайн-состояние.

## Приёмка
- После успешной загрузки и перезапуска приложения с остановленным API доступны
  список и полный текст всех четырёх статей.
- При неудачной загрузке и наличии кеша показываются данные, баннер
  «Нет соединения · показываем сохранённое» и время последнего обновления.
- Без кеша показывается понятная ошибка и действие «Повторить».
- После запуска API и нажатия «Обновить» видны актуальные данные, баннер исчезает.
- Повреждённый кеш не приводит к падению; доступна повторная загрузка.
- Неуспешная загрузка не перезаписывает хороший кеш. Запись атомарная.
- Не подменяй реальную загрузку встроенным JSON. Не добавляй очередь изменений,
  синхронизацию аккаунта, service worker или внешний backend.
- Отмена запроса не должна отображаться как отсутствие сети.

Проверять с остановкой server/serve.py: авиарежим симулятора не гарантирует
отключение localhost. Зоны: Services, LibraryModel, тесты; минимальное
изменение LibraryView для статуса и сохранённых данных.
